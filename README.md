<div align="center">
  <p>
    🚦 Atividade prática utilizando <strong>Arduino UNO</strong> no <strong>Tinkercad</strong>,
    envolvendo a montagem estruturada de um <strong>semáforo de duas vias</strong>. O circuito conta com 
    <strong>LEDs</strong> (vermelho, amarelo e verde para cada via) e <strong>resistores</strong> adequados,
