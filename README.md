# GRP1_IoT_Arduino
Repositório dedicado ao desenvolvimento de um circuito com Arduino UNO, criado a partir das instruções propostas na atividade, de um semáforo de duas vias, envolvendo montagem com LEDs e resistores e programação. Projeto desenvolvido por Pedro Henrique, Luana Camargo, Gabriel Pereira, Gabriel Araújo, Caline Myrella e Vinycius Lopes.
